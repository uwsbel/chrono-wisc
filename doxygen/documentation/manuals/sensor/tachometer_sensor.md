Tachometer and Encoder Sensor Models {#tachometer_sensor}
=================================

\tableofcontents

Chrono::Sensor offers two ways to measure shaft rotation. ChTachometerSensor samples the angular
rate directly; ChEncoderSensor counts quadrature edges and reports whole counts. Both resolve their
`offsetPose` against the parent body's *reference* (REF) frame and measure about an axis of the
**sensor** frame, so a sensor mounted rotated on its parent measures about its own axis rather than
the body's.

## Tachometer

The synthetic data is generated by averaging the angular velocity of the parent body over the
collection window and reporting its component about the chosen axis, in rpm.

~~~{.cpp}
auto tachometer = chrono_types::make_shared<ChTachometerSensor>(
                        parent_body,        // body sensor is attached to
                        update_rate,        // measurement rate in Hz
                        offset_pose,        // offset pose of sensor
                        ChRotationAxis::Y   // axis of rotation to take measurements
);

tachometer->SetName("Tachometer Sensor");
tachometer->SetLag(lag);
tachometer->SetCollectionWindow(collection_time);
~~~

An optional noise model may be supplied as a fifth argument. It is applied to the whole angular rate
vector in rad/s before the axis is selected, so a cross-axis term in the model reaches the reported
axis the way it would in a real part:

~~~{.cpp}
auto noise = chrono_types::make_shared<ChNoiseNormal>(ChVector3d(0, 0, 0), ChVector3d(0.01, 0.01, 0.01));
auto tachometer = chrono_types::make_shared<ChTachometerSensor>(
                        parent_body, update_rate, offset_pose, ChRotationAxis::Y, noise);
~~~

### Tachometer Filter Graph
~~~{.cpp}
// Access tachometer data in raw format (angular velocity)
tachometer->PushFilter(chrono_types::make_shared<ChFilterTachometerAccess>());

// Add sensor to manager
manager->AddSensor(tachometer);
~~~

### Tachometer Data Access
~~~{.cpp}
UserTachometerBufferPtr data_ptr;
unsigned int last_launch = 0;
while () {
    data_ptr = tachometer->GetMostRecentBuffer<UserTachometerBufferPtr>();
    if (data_ptr->Buffer && data_ptr->LaunchedCount > last_launch) {
        std::cout << "Shaft speed: " << data_ptr->Buffer[0].rpm << " rpm at t = "
                  << data_ptr->TimeStamp << " s" << std::endl;
        last_launch = data_ptr->LaunchedCount;
    }
}
~~~

## Encoder

An incremental rotary encoder counts quadrature edges rather than sampling a rate. It accumulates
angle and reports the mean speed over the collection window derived from **whole counts**, so the
±1-count quantisation that dominates a real encoder's error at low speed and short windows falls out
of the model rather than being injected on top of it.

~~~{.cpp}
auto encoder = chrono_types::make_shared<ChEncoderSensor>(
                        parent_body,        // body whose rotation is counted
                        update_rate,        // measurement rate in Hz
                        offset_pose,        // offset pose of sensor
                        ChRotationAxis::Y,  // axis of rotation to count
                        1024,               // lines per revolution of the disc
                        true                // quadrature: count both edges of both channels
);

// Optional imperfections.
encoder->SetMissingPulseProbability(1e-4);   // a dirty or damaged disc: lost counts never catch up
encoder->SetEccentricity(1e-4, 0.0);         // once-per-revolution angular error [rad]

encoder->PushFilter(chrono_types::make_shared<ChFilterEncoderAccess>());
manager->AddSensor(encoder);
~~~

With quadrature enabled the resolution is four times the line count:
`GetCountsPerRevolution()` returns 4096 for the example above, and `GetResolution()` returns
\f$2\pi/4096\f$ radians per count.

### Encoder Data Access
~~~{.cpp}
UserEncoderBufferPtr data_ptr;
unsigned int last_launch = 0;
while () {
    data_ptr = encoder->GetMostRecentBuffer<UserEncoderBufferPtr>();
    if (data_ptr->Buffer && data_ptr->LaunchedCount > last_launch) {
        EncoderData data = data_ptr->Buffer[0];
        std::cout << "angle " << data.angle       // rad, quantised to whole counts
                  << "  counts " << data.counts   // signed, accumulated
                  << "  rpm " << data.rpm         // from counts over the window
                  << "  dir " << data.direction   // +1, -1 or 0
                  << std::endl;
        last_launch = data_ptr->LaunchedCount;
    }
}
~~~

The accumulated angle is measured from the encoder's first sample, not from the simulation origin:
an incremental encoder counts from wherever it was switched on. Compare differences between samples
rather than absolute values against simulation time.
